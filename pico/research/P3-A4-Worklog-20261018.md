## Открытые вопросы

- PVR userspace явно передаёт buffer ID как QBUF `userptr` и использует поле, возвращённое DQBUF, как key для поиска записи. Но kernel/driver roundtrip значения не исследован: равенство ключа и исходного ID остаётся **PARTIAL**.
- Найти Qualcomm CSLAlloc source/API contract для CPU pointer ↔ exported FD backing identity.
- Не приравнивать `CSLTimestampTypeQtimer` к physical SOF/exposure без документации или независимого sensor event.
- Runtime fallback frequency, timestamp freshness, device/host clock relation, pose and Lighthouse geometry остаются unmeasured.
