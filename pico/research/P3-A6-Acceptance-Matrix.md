## Будущие runtime acceptance

Тесты на synthetic fixture не засчитываются как device evidence.

## Неизменяемые gates

На всём M0 и до получения независимых доказательств остаются `false`:

```text
exact_time=false
mapping_verified=false
pose_verified=false
shared_buffer_identity_verified=false
frame_meta_bridge_verified=false
live_lighthouse_correction_allowed=false
physical_event_verified=false
```

`SYNTHETIC PASS` не переводится в `STATIC PASS` или hardware `PASS`. Повышение runtime статуса допустимо только после review приватного evidence package по этой матрице и соответствующей отдельной approval scope.

`MOCK + POSIX INTEGRATION PASS OFFLINE` подтверждает поведение collector на injected fixtures и POSIX shell parsing/quoting в WSL. Exact Android property tuple подтверждает только Phoenix-family software identity; Pico 4 Pro international Pico OS уже является owner-confirmed project fact, но Android tuple не выступает независимой hardware attestation. Offline results не являются ADB-to-device results и не повышают R1–R10. Открытый `/dev/videoN` fd без наблюдённого `ioctl(fd,0xc01856c0,...)` остаётся недостаточным для R1.
